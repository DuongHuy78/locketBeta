# Locket Clone
## Features
- [x] Zoom in and out of the camera by your fingers
- [x] Take photos
- [x] Double tap to switch between front and back camera
- [x] Enable and disable flash
- [x] Preview of the photo taken
- [x] Swipe up to view photos you took
